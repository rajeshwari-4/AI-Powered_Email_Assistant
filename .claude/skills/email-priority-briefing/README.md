# Email Priority Briefing (Daily / Weekly / Monthly)

## What This Skill Does
This skill reviews everything that landed in your Gmail inbox over a period you choose — Daily, Weekly, or Monthly — and picks out the emails that actually need a response from you. It ranks them by urgency and hands you back one short HTML briefing, instead of you re-reading the raw inbox yourself, plus a spoken-audio summary (.mp3) of that same briefing so you can listen to it instead of reading it. Afterward, it can also create Gmail drafts (never sent) replying to the tier(s) you choose, so those replies are one review-and-send away.

## How to Invoke It
- No input file is needed — just ask for an email briefing/digest/summary (e.g. "run my email priority briefing").
- The skill always asks first whether you want a **Daily**, **Weekly**, or **Monthly** window — it never assumes monthly just because that's the skill's name.
- Requires a Gmail MCP connector already installed and authorized in Claude, with both read and draft-creation capability; the skill will not guess at email content if that connection isn't available, and will never use a send capability even if one exists.
- Generating the audio companion requires internet access at run time and the `gTTS` Python package (`pip install gTTS`) — if that step fails, the HTML briefing is still delivered.
- Optionally, name a specific date range in your request if none of the three standard cadences fit.

## What You'll Get
1. **Priority Briefing (HTML)** — a single HTML document, sectioned by priority tier (e.g. Urgent, Needs Response, FYI), listing up to the 20 highest-priority emails from the chosen period with sender, subject, and a 1-2 sentence factual summary each. Structure defined in `templates/1-priority-briefing-template.md`.
2. **Audio Summary (.mp3)** — a short spoken narration of the same tiered content, saved next to the HTML briefing in `briefings/<cadence>/<label>/` (a date for Daily, a date range for Weekly, a month name for Monthly). Generated by `scripts/generate_audio_summary.py`.
3. **(Optional) Gmail Drafts** — after the briefing, the skill asks which tier(s) you want drafted. For each email in those tiers with a real human correspondent, it creates an unsent Gmail draft reply. Automated/no-reply senders (bills, dues, system alerts) are flagged instead, never force-drafted. Nothing is ever sent automatically.

## Directory Guide
- `references/` — the domain knowledge this skill draws on: what counts as "important," ranking logic, pitfalls to avoid, drafting-consent rules, and the quality checklist. Read these to understand *why* the skill behaves the way it does.
- `templates/` — the exact HTML structure the briefing must follow, for any cadence. There is one template, matching the skill's one visible-document deliverable.
- `examples/` — reserved for sample briefings once the skill has been run against real inbox data; currently empty.
- `scripts/generate_audio_summary.py` — deterministic helper that turns a narration script into an `.mp3` and files it under `briefings/<cadence>/<label>/`, alongside a copy of the HTML briefing. This is the one part of the skill that's fixed logic rather than a judgment call.

## Where Briefings Are Saved
Each run's HTML briefing and audio summary live together under `briefings/<cadence>/<label>/` at the project root, e.g. `briefings/monthly/July 2026/briefing.html` and `.../summary.mp3`. **This folder contains your real inbox content and is excluded from version control (`.gitignore`)** — it should never be committed or pushed to a shared/public repo.

## Next Steps
- Confirm your Gmail MCP connector is installed and authorized (with draft-creation capability) before the first run.
- Run `pip install gTTS` once if you want the audio companion (optional — the HTML briefing works without it).
- Run the skill once for each cadence you plan to use and check the output against `references/validations.md`.
- If the output looks right, save that run's HTML file into `examples/` as a reference case for future comparison.
